# Changes - December 2, 2024

## Summary
Fixed deadlock issues when running parallel layer experiments on Google Colab with single GPU.

## Problem
Parallel execution on Colab would hang indefinitely due to nested multiprocessing with CUDA:
- ProcessPoolExecutor spawns multiple processes
- Each process creates DataLoaders with multiple workers
- All workers compete for single GPU
- Result: Deadlock

## Solution
Set `num_workers=0` in DataLoaders to disable nested multiprocessing:
- Data loading happens in main process
- No worker process competition
- Stable, reliable execution
- Slightly slower but prevents deadlocks
